1.1 - Convert 234 (which is in base-10) to its binary form. (2 marks)
divide 234 by 2 repeatedly
234 / 2 = 117 rem 0
117 / 2 = 58 rem 1
58 / 2 = 29 rem 0
29 / 2 = 14 rem 1
14 / 2 = 7 rem 0
7 / 2 = 3 rem 1
3 / 2 = 1 rem 1
1 / 2 = 0 rem 1

so 234 in binary = 11101010

1.2 - Convert the following binary number 11011110 to its decimal form. (2 marks)
2^1 + 2^2 + 2^3 + 2^4 + 2^6 + 2^7 
= 2 + 4 + 8 + 16 + 64 + 128 
=222

1.3 - What is the binary representation of the sum of 251 and 4? (2 marks)
251 + 4 = 255
255 / 2 = 127 rem 1
127 / 2 = 63 rem 1
63 / 2 = 31 rem 1
31 / 2 = 15 rem 1
15 / 2 = 7 rem 1
7 / 2 = 3 rem 1 
3 / 2 = 1 rem 1
1 / 2 = 0 rem 1

so 255 in binary = 11111111

1.6 - What is the binary representation of 65 - 17? (2 marks)
65 - 17 = 48
48 / 2 = 24 rem 0
24 / 2 = 12 rem 0
12 / 2 = 6 rem 0
6 / 2 = 3 rem 0
3 / 2 = 1 rem 1
1 / 2 = 0 rem 1

so 48 in binary = 000011
